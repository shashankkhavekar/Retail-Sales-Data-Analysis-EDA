# Retail Sales Data Analysis – EDA

## OASIS INFOBYTE Data Analytics Internship

**Task:** Level 1 – Task 1: Exploratory Data Analysis on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset containing 100,000 transactions and 15 original columns covering 2023–2025.

The objective is to understand sales performance, customer purchasing behaviour, product performance and business trends using Python data analytics libraries.

*Note: The dataset is synthetic and created for educational and internship practice.*

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Dataset Information

- Total Records: 100,000
- Original Columns: 15
- Period: 2023–2025
- Domain: Retail Sales

## Project Workflow

1. Data Loading and Inspection
2. Descriptive Statistics
3. Data Cleaning
4. Feature Engineering
5. Univariate Analysis
6. Bivariate Analysis
7. Time Series Analysis
8. Customer Analysis
9. Product Analysis
10. Correlation Analysis
11. Advanced Business Insights
12. Business Recommendations

## Key Analysis Areas

- Monthly, quarterly and yearly sales trends
- Customer age and gender distribution
- Top 10 best-selling products
- Product category revenue analysis
- Customer spending behaviour
- Sales channel comparison
- City-wise revenue analysis
- Correlation heatmap
- Seasonal sales patterns

3. Install the required libraries:

4. Upload the dataset if necessary.
5. Run the notebook cells sequentially.
